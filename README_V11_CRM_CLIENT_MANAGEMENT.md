# Thomas Phiri Portfolio V11 — CRM & Client Management

V11 adds a client-management workspace to the V10 Sales Command Centre.

Features:
- Client/lead records
- Search and status filtering
- Follow-up tracking
- Proposal count
- Priority tracking
- Activity timeline
- Add-record modal
- Responsive design
- Self-contained HTML/CSS/JS

The demo data is illustrative and can later be connected to a real database/CRM backend.
