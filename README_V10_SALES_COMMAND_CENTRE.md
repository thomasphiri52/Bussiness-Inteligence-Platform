# Thomas Phiri Portfolio V10 — Sales Command Centre

V10 extends the V9 client portal with an executive-style Sales Command Centre.

## Included
- Active lead KPI
- Pipeline value
- Weighted pipeline value
- Win-rate indicator
- Filterable opportunity pipeline
- Sales action shortcuts
- Responsive layout
- Self-contained HTML/CSS/JS

The pipeline uses illustrative client opportunities and can later be connected to a real CRM/backend.
