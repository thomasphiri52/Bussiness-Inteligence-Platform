# V28 Release Notes

V28 adds a read-only client self-service portal for linked project progress, milestones, invoices, payment history and client-visible document metadata. Includes `supabase/v28_client_self_service.sql` and `README_V28_CLIENT_SELF_SERVICE_PORTAL.md`.

Setup and security testing are required before production use. The portal does not override or replace Supabase RLS policies.
