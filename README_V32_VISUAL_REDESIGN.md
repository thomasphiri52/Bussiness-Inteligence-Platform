# V32 — Neon Glass Visual Redesign

This release restyles the portfolio with a deep navy background, cyan/blue/purple gradient accents, glass-like cards, soft glows, and responsive mobile styling inspired by the supplied visual reference. Existing sections and JavaScript functionality are retained.

## Deploy
1. Replace the repository files with this release (or copy the updated `index.html` into your existing repo).
2. Keep required project files and the `supabase/` folder.
3. Open `index.html` locally and check desktop and mobile layouts.
4. Commit and push to your hosting provider.

This is a front-end visual redesign; it does not by itself configure authentication, database policies, or external integrations.
